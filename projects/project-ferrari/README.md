# Project Ferrari

Starter scaffold for the new microsite.

Quick start

1. Install dependencies

```bash
cd projects/project-ferrari
npm install
```

2. Run dev server

```bash
npm run dev
```

Notes
- Arizona fonts are copied into `public/fonts/arizona/` and loaded from `/fonts/arizona/arizona-fonts.css`.
- Figma image assets are stored in `public/images/` so the project does not depend on expiring MCP asset URLs.
- GSAP is included for section motion. Native CSS scroll snap controls the hero, chapter carousel, and three snappable lot sections; the editorial section uses normal scrolling.
