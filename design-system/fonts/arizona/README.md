# Arizona Fonts

Import `arizona-fonts.css` from this directory before using the Arizona font families.

The stylesheet defines these font family variables:

- `--font-family-arizona-sans`
- `--font-family-arizona-serif`
- `--font-family-arizona-flare`

It also defines font weight variables from thin through bold. The stylesheet uses relative font URLs, so keep it with the included `.woff2` files.
